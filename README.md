# Zahnarztpraxis – Portfolio Demo

Moderne, responsive Demo-Website für eine fiktive Zahnarztpraxis in München.

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- React Hook Form + Zod
- Zustand (UI-State, Toasts)
- Lucide React

## Starten

```bash
npm install
npm run dev
```

Öffnen Sie [http://localhost:3000](http://localhost:3000).

## API

- `GET /api/appointments` – alle Terminanfragen (JSON-Datei + In-Memory-Fallback)
- `POST /api/appointments` – neue Terminanfrage mit Server-Validierung

## Hinweis

**This website is a demo project for my portfolio.** Es handelt sich nicht um eine echte Zahnarztpraxis.
